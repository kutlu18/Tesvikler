# Backend Template (Clean + Modular)

Bu iskelet, CRM entegrasyonlu tesvik platformu icin katmanli ve SOLID uyumlu .NET backend baslangic yapisidir.

- `Api`: HTTP giris katmani
- `Application`: Use-case ve orchestration
- `Domain`: Saf is kurallari
- `Infrastructure`: DB, entegrasyonlar, messaging
- `Workers`: Background islemler
- `Shared`: Ortak kontratlar ve event modelleri
- `tests`: Unit / Integration / Contract testleri
