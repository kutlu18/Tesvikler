# Changelog

All notable changes to this project will be documented here.

The project follows a lightweight semantic versioning flow:

- `MAJOR`: incompatible product/data model changes
- `MINOR`: new modules, user-visible features, Supabase schema additions
- `PATCH`: fixes, copy changes, test/documentation updates

## [0.1.0] - 2026-05-20

### Added

- Initial React/Vite incentive analysis platform.
- Supabase schema migrations for profiles, analyses, notes, activity logs, and documents.
- Business analyst UAT calculation test runner.
- Tester and UAT documentation.

### Changed

- Eximbank product filtering now respects selected financing need categories.
- Supabase RLS policies optimized for authenticated users.
